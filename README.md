# Weather Forecasting Web App

A simple and responsive weather forecasting web application built using
HTML, CSS, and JavaScript. The app fetches real-time weather data using
a public weather API and displays current weather conditions for any city.

This project is designed to be beginner-friendly, easy to understand,
and suitable for interviews and academic submissions.

---

## 🌟 Features

- Search weather by city name
- Displays temperature, humidity, wind speed, and weather condition
- Real-time weather data using API
- Clean and modern full-screen UI
- Error handling for invalid city names

---

## 🛠️ Tech Stack

- **HTML** – Structure of the web app  
- **CSS** – Styling and layout  
- **JavaScript** – Logic and API handling  
- **Weather API** – For fetching live weather data
